# acopio-frontend

Frontend for Acopio, built with [Vue.js](https://vuejs.org/).

## Requirements

- Node.js (LTS)
- npm

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run preview` — preview the production build
