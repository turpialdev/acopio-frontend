# Códigos de voluntario + permisos del voluntario

Alcance: Mínimo
Código: 7
Depende de: Inventario: entradas/salidas, listado y totales derivados (Inventario%20entradas%20salidas,%20listado%20y%20totales%20der.md)
Estado: Listo para tomar
Historias: R6, V1, V2, V3

## Qué construir

El responsable crea códigos de voluntario con etiqueta autodeclarada ("Juan – puerta") y los revoca. El voluntario canjea su código y registra entradas/salidas (flujo de alta frecuencia, mínimos toques, máxima usabilidad móvil) y consulta el inventario; puede corregir solo sus registros propios y recientes; no edita la ficha, no crea códigos, no toca registros ajenos (ADR 0002).

## Criterios de aceptación

- [ ]  El responsable crea, etiqueta y revoca códigos de voluntario.
- [ ]  El voluntario entra con su código y registra movimientos con pocos toques.
- [ ]  El voluntario solo corrige sus registros propios recientes; no edita ficha ni crea códigos ni toca ajenos.
- [ ]  Revocar un código corta su acceso de inmediato.
