## Qué construir

Fusionar centros duplicados. Reemitir/revocar el código raíz de un centro (recuperación mediada por moderador, usando el teléfono de recuperación como pista; caída a re-registrar + fusionar). Gestionar el catálogo de categorías (alta/baja, marcar `es_insumo`).

## Criterios de aceptación

- [ ]  El moderador fusiona dos centros duplicados en uno.
- [ ]  El moderador reemite/revoca el código raíz de un centro (ADR 0002).
- [ ]  El moderador gestiona el catálogo (alta/baja de categorías, marcar `es_insumo`) sin desplegar (ADR 0006).
